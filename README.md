# MusicTapGame

スマホのブラウザで遊べる音ゲー。手持ちの mp3 を読み込むと譜面を自動生成する。

## 遊び方

`index.html` をブラウザで開き、曲ファイルを選んでタップでスタート。
PC ではキー `A` / `S` / `D`（または `1` / `2` / `3`）でも操作できる。
